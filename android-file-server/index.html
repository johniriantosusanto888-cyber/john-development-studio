App Features & Functions

Everything you need to share files seamlessly across all your devices

Wireless File Transfer

Share files instantly over your local Wi-Fi network. No USB cables, no Bluetooth pairing, and no internet connection required. Just start the server and connect from any device.

QR Code Connection

Simply scan the QR code displayed in the app with any other device to instantly access the file server. No need to type long IP addresses manually.

Cross-Platform Access

Works with any device that has a web browser — Windows, Mac, Linux, iPhone, iPad, Android, and more. Access your files from anywhere on the same network.

Transfer images, music, videos, documents, APK files, and many other formats. Drag and drop files directly in the browser or use the file picker.

Private & Secure

All transfers happen locally on your Wi-Fi network. No files are uploaded to the cloud or any external server. Your data stays completely private.

Lightning Fast Speed

High-speed local network transfer that outperforms cloud uploads and Bluetooth. Transfer large files in seconds, not minutes.

Camera Filters

Apply real-time filters to your remote camera feed. Choose from multiple color presets — Mono, Sepia, Cool, Warm, Vintage, and more. Changes apply instantly on both phone and browser.

Flash & Torch Control

Toggle LED flash and continuous torch directly from the app or remote browser. Auto-detect if your device has an LED, and switch between Off / On / Auto flash modes.

Aspect Ratio Presets

Choose from 3:4, 9:16, 1:1, or Full aspect ratio for your camera preview and captured photos. Your preference is saved automatically for the next session.

Cache Cleanup

Built-in cache cleaner shows how much space the app is using and clears it with one tap. Keep your phone storage tidy without going to Settings.

Keep Screen On

Optional toggle keeps your screen awake while the server or camera is running. Prevents interruption during long transfers or streaming sessions.

Sound Effects

Audio feedback for key actions: server start/stop, camera start/stop, and shutter capture. Know what's happening without looking at the screen.

User Guide

Step-by-step instructions to start sharing files and more

1

Installation & Setup

Download the app from Google Play Store or GitHub. Install and open the app. Grant the following permissions:

  • Wi-Fi / Network Access: Required to create and run the local file server.
  • Storage Access: Needed to access files for sharing and saving received files.
  • Camera Access: Required only for the Remote Camera feature.
  • Keep Screen On (optional): Prevents the server from stopping when your screen turns off.
2

Connect Devices to Same Wi-Fi

Make sure both your Android device (sender) and the receiving device are connected to the same Wi-Fi network. This can be:

  • Your home or office Wi-Fi router.
  • Android Hotspot (mobile hotspot from the sender device).
  • Any shared local network connection.
3

Start the File Server

Open the Android File Server app and tap the "Start Server" button. The app will:

  • Display your device's local IP address (e.g., http://192.168.1.100:8080).
  • Generate a QR code for quick connection.
  • Show server status as "Running" with a green indicator.
  • Auto-enable "Keep screen on" toggle to prevent interruption.
4

Connect & Transfer Files

On the receiving device (PC, Mac, iPhone, iPad, or another Android), do one of the following:

  • Scan QR Code: Open the camera app and scan the QR code displayed on your Android device.
  • Enter IP Address: Open any web browser and type the IP address shown in the app.
  • Upload to Android: Drag and drop files into the browser or click "Select Files".
  • Download from Android: Browse the shared folders and click on any file to download.
5

📷 Using the Remote Camera

Tap "Open Remote Camera" on the main screen to launch the camera module:

  • Start Camera: Tap "▶ Start Remote Camera" — a URL and QR code will appear.
  • Open on PC: Scan the QR code or open the URL on your PC browser.
  • Control Filters: Pick filters on the phone or from the browser — they sync instantly.
  • Flash / Torch: Use the ⚡ and 🔦 buttons to control the LED.
  • Aspect Ratio: Choose 3:4, 9:16, 1:1, or Full at the top of the preview.
  • Capture: Tap the shutter on the phone or click the button in the browser.
  • Gallery: Tap the gallery icon to view all captured photos.
6

🎵 Using the Audio Converter

Tap "Open Audio Converter" on the main screen:

  • Pick a File: Select an audio file from your device storage.
  • Choose Format: Pick the target output format (MP3, AAC, WAV, etc.).
  • Convert: Tap "Convert" — the process runs entirely on your phone.
  • Save: The converted file is saved to your Download folder.
7

📁 File Browser & Cache Cleanup

Manage your received files and free up space:

  • Open Download Folder: Browse all files in Download/AndroidFileServer/.
  • Preview Files: Tap images or videos to preview them inline.
  • Clear Cache: Use the 🧹 Clear Cache card to free up storage — shows current usage and clears with one tap.
8

Stop & Troubleshooting

When done, tap "Stop Server" or "Stop Camera" to close the connection. If you encounter issues:

  • Can't connect: Ensure both devices are on the exact same Wi-Fi network (same SSID).
  • Firewall blocking: Disable firewall temporarily or allow port 8080 on your router.
  • Server stops unexpectedly: Enable "Keep screen on" toggle or disable battery optimization for the app.
  • Camera preview lag: Move closer to the Wi-Fi router for better signal strength.
  • VPN issues: Disable VPN on your PC — it may block access to the local server.
