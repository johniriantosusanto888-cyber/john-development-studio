🔒 Privacy Policy

Air Drop - Android File Server

Effective date: October 2026

✅ No Personal Data Collected by the Developer

Air Drop - Android File Server ("the App") is developed by John Irianto Susanto. This Privacy Policy explains how the App handles your data. We are committed to protecting your privacy.

The Developer does not collect, store, or have access to your personal files, camera preview, photos, videos, or audio recordings created through the Remote Camera feature. File transfers, audio conversions, and Remote Camera operations are performed by the App on the user's device and through the App's local web server.

1. Information The Developer Does NOT Collect

The developer does not collect or have access to:

  • Personal identification information (name, email, phone number)
  • Location data
  • Contacts or calendar data
  • Browsing history
  • The actual contents of files transferred or converted
  • Camera preview data from the Remote Camera feature
  • Photos captured using the Remote Camera feature
  • Videos recorded using the Remote Camera feature
  • Audio recordings captured with video recordings
  • Microphone input at any time

Note on Device Identifiers: While the Developer does not directly use these identifiers for personal identification, third-party services used by the App, such as Google AdMob and Firebase Analytics, may collect device identifiers, advertising identifiers, IP addresses, and usage information according to their respective policies.

2. How the File Server Works

The App creates a local Wi-Fi web server on your Android device. Files are transferred directly between your device and other devices connected to the same local network. No file data is routed through the Developer's server.

📶 File transfers are designed for local network use — the Developer does not receive or store the files being transferred.

3. Remote Camera

The App includes an optional Remote Camera feature that allows the user to use the Android device camera and control the camera through the App's web interface.

The camera is activated only when the user explicitly starts the Remote Camera feature. The App does not automatically activate the camera without the user's action to start the feature.

When Remote Camera is active:

  • The Android device camera provides a live camera preview through the App's web interface.
  • The user can remotely trigger the camera shutter from the web interface.
  • The camera/server activation is indicated to the user.
  • A sound effect is played when the Remote Camera server is started.
  • A shutter sound is played when a photo is captured.
  • The user can stop the Remote Camera feature at any time.
📷 Remote Camera is an optional user-initiated feature. The camera is not activated automatically by the App.

The Remote Camera feature uses the App's web server to provide camera controls and camera preview to a connected web browser. Camera preview data and captured photos are handled by the App and the connected devices and are not collected or stored by the Developer.

The Developer does not have access to the camera preview, captured photos, or Remote Camera sessions.

3.1 Video Recording (with Optional Audio)

The Remote Camera feature includes an optional video recording mode. When the user starts a video recording:

  • Video is recorded from the device camera and saved to the local folder Download/AndroidFileServer/ on the user's device.
  • If the user has granted the microphone permission (RECORD_AUDIO), audio from the device's microphone is recorded together with the video.
  • If the user has not granted microphone permission, or has revoked it, the video will be recorded silently without audio — the App never blocks recording because of missing audio.
  • Audio capture begins only when the user explicitly starts a video recording, and ends when the user stops it.
  • Audio is never captured in the background, never transmitted over the internet, and never sent to any external server.
🎙️ Audio is captured only while the user is actively recording video, and is stored only on the user's own device. The Developer has no access to any audio recordings at any time.

4. Microphone & Audio Recording

The App requests permission to access the device microphone (android.permission.RECORD_AUDIO) only to enable audio recording synchronized with video in the Remote Camera's video mode.

The microphone permission is used for the following purposes:

  • Recording audio together with video when the user activates video mode.

The microphone is NOT used for any of the following:

  • Background audio recording
  • Voice recognition or speech-to-text
  • Phone call recording
  • Audio fingerprinting
  • Advertising or user profiling
  • Any purpose other than the local video recording feature described above

4.1 Local Storage Only

All audio recordings are stored locally on your device in the folder Download/AndroidFileServer/ inside the recorded .mp4 video file. Audio is:

  • Never uploaded to any external server
  • Never shared with third parties
  • Never transmitted over the internet by the Developer
  • Accessible and deletable by you at any time via your device's file manager

4.2 Optional — Not Required for the App

The microphone permission is optional. If you deny or revoke the microphone permission:

  • The App will continue to work normally.
  • Video recording will still work, but without audio.
  • You can enable microphone access later through your device Settings → Apps → Air Drop - Android File Server → Permissions.
🔐 You have full control over the microphone permission. The App only uses the microphone after you explicitly grant the permission and explicitly start a video recording.

5. Audio Conversion

The App includes an Audio Converter (MP3 and OGG). This feature uses open-source libraries (LAME and AndroidX Media3) to convert files. All conversion happens on your device. The files you convert are not uploaded to or stored by the Developer.

6. Advertising & Analytics

The App uses Google AdMob for advertising and Firebase Analytics for usage statistics and analytics. These services are provided by Google and may collect information such as device identifiers, advertising identifiers, IP addresses, and app usage data in accordance with their own privacy policies and applicable settings.

https://policies.google.com/privacy

This data collection is managed by the applicable Google services and is subject to Google's terms and policies. The Developer does not have access to the personal data collected by Google for advertising and analytics purposes beyond information made available through those services.

Note: AdMob and Firebase Analytics do not have access to the microphone, camera, or any audio/video recordings created by the App.

7. Permissions Used by the App

The App requests the following Android permissions:

  • CAMERA — to provide the Remote Camera feature (preview, photo capture, video recording).
  • RECORD_AUDIO — optional; to record audio synchronized with video recordings in Remote Camera's video mode.
  • INTERNET / ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE — to run the local web server and serve the App's web interface on the same network.
  • READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE / MANAGE_EXTERNAL_STORAGE — to save files, photos, and videos to the device's Downloads folder.
  • FOREGROUND_SERVICE / FOREGROUND_SERVICE_DATA_SYNC — to keep the file server running while the App is in the background.
  • WAKE_LOCK — to prevent the device from sleeping while the server or camera is running.
  • POST_NOTIFICATIONS — to display the foreground service notification.

You can review and revoke any permission at any time through your device Settings → Apps → Air Drop - Android File Server → Permissions.
