Kebijakan Privasi

Terakhir diperbarui: 1 September 2026

Terima kasih telah menggunakan InvoiceApp yang dikembangkan oleh John Irianto Susanto. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda ketika menggunakan aplikasi ini.

1. Informasi yang Kami Kumpulkan

Kami mengumpulkan beberapa jenis data untuk menjalankan fitur utama aplikasi:

  • Data Akun: Email dan ID pengguna yang kami dapatkan dari proses login menggunakan Google Sign-In (Firebase Authentication).
  • Data Profil Bisnis: Nama bisnis, alamat, nomor telepon, email bisnis, dan logo perusahaan yang Anda unggah.
  • Data Klien dan Produk: Nama, alamat, kontak klien, serta daftar produk dan harga yang Anda input ke dalam aplikasi.
  • Data Faktur: Nomor invoice, tanggal, detail barang/jasa, diskon, pajak, ongkir, status pembayaran, catatan, dan instruksi pembayaran.
  • Data Perangkat (Iklan): Aplikasi ini menggunakan Google AdMob untuk menampilkan iklan. AdMob dapat mengumpulkan ID Iklan (Advertising ID) dan data penggunaan perangkat untuk menampilkan iklan yang relevan.

2. Penggunaan Informasi

Informasi yang kami kumpulkan digunakan untuk:

  • Menyediakan dan memelihara fitur inti aplikasi (membuat, mengedit, dan melihat invoice).
  • Menyimpan data Anda ke cloud (Firestore) agar otomatis sinkron dan dapat diakses kembali dari perangkat lain.
  • Menghasilkan file PDF invoice yang siap dibagikan.
  • Menampilkan iklan untuk mendukung pengembangan aplikasi agar tetap gratis.
  • Memproses transaksi pembayaran dan mengelola status (Lunas, Partial, dsb).
  • Meningkatkan performa dan keamanan aplikasi.

3. Penyimpanan dan Keamanan Data

Data Anda disimpan di dua tempat:

  • Penyimpanan Lokal (Device): Aplikasi menggunakan database lokal (Room) agar cepat diakses saat offline.
  • Cloud (Firestore): Data disinkronkan ke server Google Firebase yang aman dan terenkripsi.

Kami mengambil langkah keamanan yang wajar untuk melindungi data Anda dari akses tanpa izin. Namun, perlu diingat bahwa tidak ada metode transmisi atau penyimpanan di internet yang 100% aman.

4. Berbagi Data Pihak Ketiga

Kami TIDAK menjual, memperdagangkan, atau mentransfer data Anda kepada pihak lain untuk tujuan pemasaran. Data hanya dibagikan kepada penyedia layanan tepercaya yang membantu kami menjalankan aplikasi, seperti:

  • Google Firebase: Untuk menyimpan data dan autentikasi.
  • Google AdMob: Untuk menampilkan iklan (sebagaimana diatur dalam kebijakan privasi Google).

5. Izin Aplikasi

Aplikasi ini menggunakan izin akses yang relevan, seperti akses penyimpanan sementara (cache) untuk membuat dan membagikan file PDF invoice.

6. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak-anak. Jika Anda yakin anak Anda memberikan data pribadi kepada kami, segera hubungi kami agar kami dapat menghapus data tersebut.

7. Hak Pengguna

Anda memiliki hak untuk:

  • Mengakses dan memperbarui data profil bisnis, produk, dan klien Anda.
  • Menghapus semua data dengan menggunakan fitur "Hapus Semua Data" (Factory Reset) yang tersedia di dalam aplikasi.
  • Menghapus akun dan seluruh data dari server kami dengan menghubungi dukungan.

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diumumkan melalui aplikasi atau situs web ini. Tanggal pembaruan terakhir akan selalu ditampilkan di bagian atas halaman ini.
