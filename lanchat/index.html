App Features & Functions

Everything you need for fast, private, and reliable local messaging

Chat Over Wi-Fi or Hotspot

Connect multiple devices to the same Wi-Fi router or use one phone as a mobile hotspot. LanChat creates a local communication network instantly — no internet needed.

No Internet Required

Works completely offline using your local network. No mobile data, no external servers, no cloud dependency. Perfect for areas with poor or no internet coverage.

Automatic Nearby User Discovery

The app automatically scans and discovers all LanChat users connected to the same network. See device names and IP addresses in real-time with a single tap to refresh.

Fast Local Network Messaging

Messages are delivered instantly over your local Wi-Fi with minimal latency. Experience real-time chat speed comparable to popular messaging apps — but without the internet.

Private & Group Chat

Enjoy one-to-one private conversations or create group chats for multiple participants. Perfect for family rooms, classrooms, offices, and team coordination.

Send Images & Files

Share photos, screenshots, and files directly within the chat. Images appear inline with sender info and timestamps for easy reference.

Privacy First

Your messages stay within your local network and are never stored on external servers. No accounts, no phone numbers, no tracking — just pure local communication.

Simple & Lightweight

Clean, user-friendly interface designed for everyone. Minimal battery and resource usage. No unnecessary bloat — just open the app, enter your name, and start chatting.

User Guide

Step-by-step instructions to start chatting instantly

1

Installation & First Launch

Download LanChat from Google Play Store or GitHub. Install and open the app. On the welcome screen:

  • Enter your preferred display name (e.g., "John", "PixelNova X7").
  • Tap START CHATTING to enter the main screen.
  • Tap USER GUIDE anytime to revisit these instructions.
2

Connect All Devices to the Same Network

For LanChat to work properly, all users must connect to the SAME Wi-Fi network or hotspot:

  • Recommended: Connect all devices to one Wi-Fi router.
  • Alternative: Use one phone as a mobile hotspot and connect all other devices to it.
  • Different Wi-Fi networks will prevent messages from being delivered.

Tip: Make sure everyone joins the same network before starting the chat for the best experience.

3

Discover Nearby Users

On the main screen, LanChat will automatically scan for other users:

  • Your device name and ID appear at the top (e.g., "You: PixelNova X7").
  • Tap REFRESH to scan for newly connected users.
  • Discovered users appear in a list with their device name and IP address.
  • Each user shows a status indicator (green dot = online).
4

Start a Private Chat

Tap on any discovered user to start a one-to-one conversation:

  • Type your message in the text field at the bottom.
  • Tap the + button to attach and send images or files.
  • Tap SEND to deliver your message instantly.
  • Messages appear with sender name and timestamp.

Note: Images sent will be displayed inline in the chat thread.

5

Create & Join Group Chats

Tap GROUPS to access the group chat feature:

  • Tap + NEW GROUP to create a new group chat room.
  • Give your group a name (e.g., "Ultra Home", "Classroom A").
  • Other users on the network can see and join available groups.
  • Tap OPEN to enter a group, or LEAVE to exit.
  • Tap REFRESH to update the group list.
6

Tips for Best Performance

Get the most out of LanChat with these recommendations:

  • Same Network: Always ensure all devices are on the identical Wi-Fi or hotspot.
  • Refresh Often: Tap REFRESH when new users join to see them immediately.
  • Stable Connection: Keep your Wi-Fi signal strong for reliable message delivery.
  • No Internet Needed: LanChat works perfectly offline — save your mobile data!
  • Privacy: Your messages never leave your local network. No external servers involved.
